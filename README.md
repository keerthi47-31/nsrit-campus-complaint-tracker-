# NSRIT Campus Complaint Tracker
A full-stack hackathon project for NSRIT Engineering College.
## Purpose
Students can submit campus complaints such as water leakage, broken fans, Wi-Fi issues, or cleanliness problems.
Administrators can log in, view complaints, and change their status:
- Open
- In Progress
- Resolved
## Project Folders
- `frontend/` — Website pages, styling, and JavaScript
- `backend/` — Python server and API
- `data/` — Sample complaint data
- `tests/` — Backend test files
## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite database
## Team Project
